Plot, cursor and bit fields

01-plot.mf4 simulates 12 seconds of speed tracking. The target steps from 36 to 54 km/h at 2 s and then to 42 km/h at 8 s.

  1. Press X to see all values at the cursor. With TutorialSpeed selected, click near 2 s and move toward 4 s to see the time and speed differences. Esc ends the measurement.
  2. Drag in the plot to zoom in time. P and N move between time windows. Press Space to show the entire recording.
  3. Press E to open the view editor. The left list holds the recorded channels. The right list contains the view entries and can include multiple copies of one channel. Compare the measured speed's .2f with the target's .0f. An empty format uses the default, initially %g. 8b prints at least eight binary digits.
  4. Set the speed reference lines to 45; 50; max to draw two thresholds and the recorded maximum. The signal's Autoscaling option fits the extrema. The toolbar's Auto range sets a fitted display range for each analog curve on demand. By unit gives both speeds the same scale. Unit bands places signals with the same unit in the same band.

At 7.5 s TutorialFlags is 91, displayed as 01011011. BIT-P counts from the right, starting at 0. BIT-C is the number of consecutive bits to extract.

  • DIGITAL-1-Bit at P=1 reads the limited flag as 1.
  • DIGITAL-N-Bit at P=2 and C=2 reads 10 as 2.
  • Enable the two trim entries in the editor. At P=4 and C=3 both read 101. The unsigned entry gives 4 + 1 = 5. The signed two's-complement entry gives −4 + 1 = −3.

TutorialDriveMode has an embedded text table. Change Value display to compare Limited, Limited (2), and 2. Enable Show as state band to see the Limited interval between 7 and 9 s above the curves.

Processing and derived signals

02-processing.mf4 contains a speed baseline, a noisy version, and a reference acceleration, sampled every 10 ms. Press E to enable the optional copies. To make your own, select a signal and choose Signals → Duplicate selected signal with processing.

AttributeWhat you can observe
dgf=bth:3:2A second-order 3 Hz Butterworth low-pass smooths the speed with some delay. Use positive frequencies below the 50 Hz Nyquist limit here and orders from 1 to 20. The attribute also supports Chebyshev chb1 or chb2 with a dB parameter, and pdt1 or pdt2 with filter coefficients.
mavr(-10)Average the current raw sample and up to nine preceding samples. Positive mavr(10) looks forward. A repeated value contributes once per sample.
diffDivide the difference of adjacent values by their time interval. Compare the derivative of speed with the reference acceleration after the initial sample.
integAccumulate the area from time zero using each previous value over its sample interval. The speed baseline integrates to about 73.50 m at 7.5 s.
-meanSubtract the mean of the full processed series from every sample.
exp=3.6*xConvert m/s to km/h, then set the output unit to km/h. To compare two signals, try exp(x1=TutorialSpeedBaseline)=x-x1 on a copy of the noisy speed.

A ten-point backward average of 1, 1, 1, 1, 2, 2, 2, 5, 5, 5 is 2.5. If the next raw sample is 3, remove the oldest 1 and include 3. The new result is (25 − 1 + 3) / 10 = 2.7.

Other attributes include min, max, -min, -max, shift(3), and revert. The application runs attributes in the order entered.

DBC, states and timing checks

03-timing.mf4 has requests at 2 s and 6 s. Load warmup-signals.dbc under Configuration → Signal databases. Look up TutorialInputTravel to see its nominal 20 ms cycle, 0.5% resolution, and 0–100% range. The viewer matches names to channels already recorded.

  1. Take the DBC value tables over as value mappings. Or import warmup-mapping.json from Configuration → Value mapping to load the practice table and enable its state band.
  2. With TutorialAckStatus selected, inspect the mapping from codes 0–3 to Idle, Waiting, Acknowledged, and Timed out. Try switching the display between labels, raw values, and both.
  3. You can create a table from scratch or start from the observed signal values. Use the Table selector to assign it to a signal. You can specify a default label for unmapped values. Numeric-only mappings can also produce a calculated signal.

Preview a response check

Paste the following into Analysis → Python script and click Run (preview).

rule(
    "Request response time",
    trigger=becomes((S("TutorialEnabled") == 1) & (S("TutorialRequest") == 1)),
    expect=S("TutorialAck") == 1,
    within=(0.0, 0.50),
    record=["TutorialAckStatus"],
)

The first request at 2.00 s passes with a 0.24 s delay. The second request at 6.00 s fails because its acknowledgement comes at 6.72 s. To jump from a result to the plot, save the script to the rule list, press F5, and double-click the event.

Settings

  • The first launch uses the dark Obsidian theme. Switch themes in View → Theme, or adjust the line width, grid and legend in View → Appearance.
  • General controls recent-item limits, whether to keep the current view when opening another recording, and the background used for print and image exports.
  • Names of new signals previews display-name shortening on a synthetic name. The saved reference still uses the recording's name.
  • Processing and statistics selects the time basis for calculations and statistics. It also controls processing on irregular samples, access to disabled entries, and how missing calculation inputs are handled.
